SLIDE 1
BAKDAULET — 0:00–0:20. We built an image-captioning system that generates a sentence from a photograph. Our project moves from one global image vector to spatial and object-region information. We compare the models, explain the final fusion decoder, and show both improvements and remaining mistakes.

SLIDE 2
BAKDAULET — 0:20–1:05

A fluent caption must also match the image. This matters for image search and accessibility, where wrong objects or actions can mislead users. We ask three questions: which frozen encoder and decoder give the best global baseline; whether spatial locations and object regions help; and whether we can combine them while keeping the CNNs frozen. We compare complete systems and also look at individual changes. Finally, we check actual captions, because a higher overlap score does not guarantee correct visual details.

SLIDE 3
BAKDAULET — 1:05–2:05

We use 123,287 labeled COCO images: 113,287 for training, 5,000 for validation and 5,000 for our local test. Official test2017 has no public captions, so it is excluded. Our split has no overlapping image IDs or exact image hashes. The vocabulary comes only from training captions. We sample one caption per image each training epoch, and keep all references for metrics. Features are cached from frozen encoders. A key limitation is that our test comes from COCO train2017, also the source used to pretrain the detector. This is a caption-training holdout; it does not establish fully unseen-image performance for the whole system. Exact detector-training image overlap was not reconstructed.

SLIDE 4
BAKDAULET → ASKAT — 2:05–2:30

CIDEr-D is our main validation criterion. BLEU-1 measures word overlap and BLEU-4 looks at longer phrases. Every model is evaluated on all 5,000 validation images using all human captions and identical tokenization. These are project scores, not official leaderboard numbers. Askat will now explain what the experiments taught us and how the final model works.

SLIDE 6
ASKAT — 3:05–3:45

The three-layer prefix Transformer reached point eight five eight CIDEr and became our strongest global model. A fourth layer reduced quality for both decoder types. Depth also did not mean faster convergence: the three-layer Transformer selected epoch twenty-one, compared with epoch five for two layers. We used the same patience of three, so stopping happened three epochs later. Stronger dropout was also unhelpful: increasing it from point three to point five reduced CIDEr in all fifteen matched encoder-decoder pairs. We keep point three. These are single-seed observations, so we do not claim universal optimal settings.



SLIDE 7
ASKAT — 3:45–4:25

Extra visual tokens did not automatically help. The grid-attention LSTM stopped earlier but scored below the global LSTM: a worse plateau, not faster successful convergence. The region LSTM initially produced the same caption for every image. Adding LayerNorm after visual projection raised CIDEr from point zero five one to point eight one eight. The loop audit found complete optimizer coverage, no double division, and similarly weak embedding updates in FP 32 and AMP. Grid and region runs also differ in normalization and pretraining, so their difference cannot be attributed only to regions.

SLIDE 8
ASKAT — 4:25–5:20

ResNet 50 provides a global vector and forty-nine spatial positions before global pooling. A separate Faster R-CNN provides up to thirty-six numeric region vectors. We project both sources to five hundred twelve dimensions and normalize them. The grid receives row and column embeddings; regions receive box-coordinate embeddings. Source embeddings distinguish the two. Concatenation creates eighty-five memory positions, with padded regions masked. We retain the global image prefix in the word stream. The three-layer Transformer can read earlier words and attend to every valid visual token. Both CNNs are frozen; we train only fusion and the decoder.

SLIDE 9
ASKAT — 5:20–6:10

Each layer first reads the earlier words with masked self-attention. Then cross-attention lets the current text retrieve useful image details from the grid and region features. A feed-forward network transforms the result. We transfer the trained prefix model and start the new visual gate at zero, preserving the starting model in evaluation mode. The branch learns during continued training. The gate is a learned signed multiplier, not an attention probability. The exact equations are in the backup for questions.

Sources:

SLIDE 10
ASKAT — 6:10–6:45

Teacher forcing shifts the human caption by one token: input starts with start, and target ends with end. Loss averages over real target tokens and ignores padding. Generation instead uses the model’s own previous predictions. We train twenty-five point five two million parameters with Adam, AMP and clipping, using a lower learning rate for transferred weights. Checkpoints preserve optimizer and random states. The fusion run took about two and a half active hours and was manually stopped during epoch fourteen.

SLIDE 14
ASKAT — 9:05–10:00

Our strongest global model was ResNet50 with a three-layer prefix Transformer. Grid attention alone did not improve the LSTM; LayerNorm helped the regional model learn. The final fusion system with beam search achieved our best validation result, but its gain combines architecture changes and additional training. We did not isolate fusion alone. The reported test CIDEr is point nine nine eight four and BLEU-four is point three two six two. These are caption-training holdout results: the detector was pretrained on the same COCO source. Next we need an equally long continued-prefix control, repeated seeds, a formal human evaluation, partial fine-tuning and an external-image test. We exceeded the original numeric BLEU targets and expanded the evaluation beyond the midterm plan.

BACKUP — Not in the timed talk

The provided reference images illustrated a two3x3basic residual block and Fast R-CNN. This slide adapts the ideas to the actual models. ResNet50 uses bottleneck blocks with1x1,3x3,1x1convolutions and stages containing3,4,6,3blocks. A projection shortcut is used when dimensions change. Faster R-CNN adds a learned region proposal network. Our frozen torchvision ResNet50-FPN detector makes detections, applies score0.2and class-agnosticNMS0.5, keeps up to36, then re-pools the selected final boxes through the two-layerROIbox head to obtain1024-dimensional vectors. Class names and scores are not captiondecoder inputs. Neither CNN is updated by captiontraining.

SLIDE 24
BACKUP — Not part of the timed talk

The decoder has three pre-norm layers, each with masked self-attention, gated visual cross-attention and a ReLU feed-forward network of width 2048. Hidden width is 512 and there are eight heads. The gate scales the cross-attention residual and can be negative; it is not a probability. We initialize it at zero and transfer the prefix model, preserving the initial function in evaluation mode. Cross entropy is computed on next-word logits without a prior softmax and averaged over non-padding target tokens. These equations describe the actual model.
